# v0.4.30

修复字幕观测冲突被局部 OCR 超时覆盖为执行故障、反复重跑的问题，并使自动选源与手动搜索正确区分请求失败和真实空结果。保持 1080p、简中与禁止偏好回退。

- 字幕测量与评估分开版本管理。简繁读数已冲突时继续保留未知/待复核，不授予语言资格；失败采样、时间、画面摘要与耗时保留。纯工具故障及取消仍按执行故障处理。
- 完整视频摘要、尺寸与片长一致时，可从兼容的旧观测恢复冲突结论，避免重复 OCR；不兼容或文件改变必须重新测量，显式复核仍可重新运行。原生字幕轨继续独立检查。复核响应从数据库新值构建，清空已失效的重试时间。
- 聚合搜索输出候选与来源可用性。自动诊断及手动搜索展示部分/全部索引请求失败；不完整结果仅缓存一分钟，正常搜索继续缓存二十分钟。健康来源可独立提供候选，保留共用筛选与成片准入。
- Nyaa 召回使用全部动画分类，取消英语动画分类的隐含限制；全局启用设置不变，简中与画质仍由统一策略和真实媒体验收决定。

回归覆盖部分超时与冲突、旧观测兼容及内容变更、来源归属、重启与显式复核、来源故障/恢复缓存、Mikan RSS 故障及 Nyaa 中文召回。实际故障样本使用只读保留文件与隔离服务验证；合格替代成片另外校验字幕正文、同步、片尾与完整摘要。完整端到端继续覆盖独立 BT v1/v2、PostgreSQL、严格准入、安全替换、暂停重启与容量零值。
