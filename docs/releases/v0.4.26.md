# AniDog v0.4.26

修复 BT 对端库存变更后移除种子或关闭客户端可能触发底层断言、导致后端退出的问题。修正在拥有协议状态的依赖模块内：清空对端库存时，同时撤销完整种子集合或逐片可用性计数。保留断言和协议扩展，通过真实 TCP 消息在独立进程中覆盖两种存储模式、移除与关闭。依赖暂以受控源码替换保留 v1.61.0，仅携带这一处改动；CI 将全部源码与校验和验证过的上游模块比较，阻止未记录差异。

修复普通种子下载地址不含 InfoHash 时，真实传输已经完成但数据库任务停留在“下载中”的问题。引擎确认的接单身份与任务状态一同保存；旧记录仅凭实际引擎快照恢复缺失的跟踪身份。接单成功仍不代表成片完成，1080p、简中与原有验收、归档仲裁继续执行。

扩大传输后检查超时回归的启动余量，并明确断言测试已进入本地检查，避免把工具尚未启动误当作已完成传输的验收失败。设计文档记录方案取舍、源码维护成本和仍未完成的接口迁移；本次没有数据库结构变更。
