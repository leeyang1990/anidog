# AniDog v0.4.20

修复 MP4 简中字幕轨被误判为未知的问题：部分 MP4 将“中文（简体）”放在 `name` 字段，MKV 则常用 `title`。字幕轨证据与画质偏好判断现在共用同一标签解析，支持明确的简繁标签及标准语言代码；单独的 `chi`、`zho`、`zh` 仍不能证明简体。音频或数据轨的标签不能充当字幕证据。

手动 BT 搜索与自动编排共用 Indexer 构建入口及应用 HTTP 客户端，修复手动搜索绕过已配置代理后超时、表现为空结果的问题。

保持 1080p、简中要求。回归覆盖 MP4 name/handler、MKV title、简繁区域代码、中文脚本不明、非字幕轨不能放行，以及搜索请求经过应用传输层。实际保留成片验证包含两条 mov_text 字幕轨的 MP4 可被准确识别，无需重复下载或修改文件元数据。
