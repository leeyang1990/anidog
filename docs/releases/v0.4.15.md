# AniDog v0.4.15

统一下载失败语义和媒体质量策略，修复 OCR 故障误伤源健康、选源与验收偏好不一致，以及归档后质量状态延迟更新的问题。

- 取流、身份复核、预检、字幕识别、传输和成片检查提供稳定故障原因与阶段。重试和规则/番剧健康统计共用这些事实；OCR 超时、工具/存储/数据库故障、取消和品质拒收不计作站点网络故障。历史记录通过集中兼容层解释。
- 搜索、成片验收和质量审计共用质量策略。默认继续为 1080p、简中；番剧空字幕覆盖继承全局，错误配置或数据库读取失败停止执行，避免静默放宽要求。显式全局空语言数组仍表示用户不限制语言。
- 候选选择和执行复核共用目录身份与线路划分规则，保留错篇章、合并全集边界和集数编号保护。
- 归档后主动审计品质，按番剧合并重复事件，保留审计期间到达的新完成事件。新媒体使旧质量结论失效，重复完成保持有效证据；质量审计本身不创建下载。
- 下载后 ffprobe 与同番片长检查纳入超时和取消边界。传输完成后的工具检查故障保留暂存文件及任务路径；明确不合格的候选继续拒收。
- 新增回归覆盖错误文案变化、持久化故障事实、OCR 耗尽与健康隔离、统一偏好、数据库不可用、媒体替换与重复回调、完成事件合并及检查超时后的文件保留。

数据库增加可空兼容的故障原因、阶段字段，旧下载记录与已有文件继续保留。继承 v0.4.14 的请求上下文、代理路由、字幕证据、候选退避、容量保护及 BT 清理恢复机制。
