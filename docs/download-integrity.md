# 下载与剧集完整性

从 v0.4.3 起，下载任务完成和剧集入库分别判断：

- 合集使用独立暂存目录；下载器实际目录必须与任务记录一致。合集内的每一集写入独立剧集映射，界面按映射显示完成情况。
- 只有已播完且实际文件覆盖全部正片集数，才标记为已归档。已归档番剧仍检查缺集，缺失时恢复补齐。
- 自动选源检查续作编号、季数和明确篇章；缓存的流媒体绑定重新验证，避免同名上一部或其他篇章被复用。
- 已知播出日期晚于当天的剧集禁止自动入队；手动选源保留显式选择能力。
- 入库前使用 ffprobe 检查视频轨道、分辨率和时长，并使用 ffmpeg 对尾部进行有限解码检查。已知单集参考时长时，短于参考的 85%（另有 5 秒容差）会拒绝；该检查不是全片逐帧验证。
- 自动下载默认遵守分辨率与字幕/语言设置。已知不符的候选被过滤，成片也需要可确认的语言证据。无法识别的硬字幕可能需要手动选源，或在下载偏好中明确允许回退。
- 手动选择可覆盖质量和语言偏好，但仍接受文件完整性检查。缺少 ffmpeg/ffprobe 或检查超时会保留任务等待重试，不会把候选永久列为坏源。
- 参考集数使用 Bangumi 正片话数，避免把全部章节数量当成正片数量；文件大小记录以实际归档文件为准。

被拒绝的下载保留原因和候选文件，便于检查和恢复。历史错季或质量问题应先核对来源与实际文件，备份后隔离，不能只凭标题猜测或用数据库“完成”状态代替文件检查。
