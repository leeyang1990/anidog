# AniDog v0.4.22

修复内嵌 BT 在网络文件系统上校验稀疏下载文件时，依赖 SEEK_DATA 的可选读取优化可能返回 I/O 错误的问题。Docker 默认的 classic 文件存储现在通过标准 ReaderAt 完成完整分片哈希，避免稀疏区查询及可选 WriterTo 的边界行为影响校验；真实数据读取失败仍会阻止验收。原生本地存储使用的 mmap 保持原有读取路径，避免其 ReaderAt 在截短文件上的越界行为。

分片哈希、下载完成判定和 1080p、简中成片准入保持完整。新增回归覆盖可选快路径写入部分前缀后失败、普通读取失败、两种分片接口，以及 classic/mmap 两种运行模式重启后复用已保留数据并修复损坏分片。真实 NAS 分片另通过只读前后对照验证。
