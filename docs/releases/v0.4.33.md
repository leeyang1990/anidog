# v0.4.33

下载清单按实际传输类型显示阶段，所有完成任务统一显示“已完成 · 100%”。

- 来源与传输类型分开：`download_type=torrent` 使用排队、元数据、下载、完成四阶段；`download_type=stream` 使用排队、下载、完成三阶段。Mikan、RSS、手动选种等来源不再改变传输阶段。
- 完成态由后端 `status=completed` 决定，优先于传输类型、旧百分比或停滞字段，统一使用完整进度条和“已完成 · 100%”。下载字节到 100% 但尚未验收的任务继续显示下载中。
- 新 `DownloadTaskProgress` 组件负责进度渲染和通用终态，纯函数 `resolveDownloadStage` 只推导已知下载类型的阶段。列表移除重复分支；未知类型保留普通进度，不猜成 BT。字幕待复核、候选拒收、证据复用保持原有分类。
- 回归覆盖来源与类型交叉、缺失/未来类型、流媒体零字节、下载到 100% 尚未完成、旧百分比和终态一致性，并渲染实际 Vue 组件验证接线。隔离浏览器夹具位于 `frontend/tests/fixtures/download-progress.html`，通过 Vite 开发服务器访问，不进入产品构建，也不连接下载服务。

本次仅修改前端展示，不变更下载状态、媒体准入、1080p/简中偏好、证据、归档或数据库模型。
