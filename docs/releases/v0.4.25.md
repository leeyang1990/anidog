# AniDog v0.4.25

修复 BT 暂停、排队时数据许可与待请求分片不同步，可能导致底层引擎断言退出的问题。下载器适配层统一转换任务意图：停止时先撤销分片请求需求，再禁止数据传输；恢复时先开放传输，再恢复分片需求。暂停与并发队列共用同一机制，保留磁盘数据、暂停状态和任务归属。新回归在独立进程中通过公开调度接口稳定复现旧问题，并验证 classic/mmap 两种模式的暂停、恢复和队列切换。

画质标签解析移到独立共享模块，搜索排序、偏好解析与媒体验收共用定义，验收和策略不再反向依赖搜索模块；现有 1080p、简中要求及标签兼容语义保持。

新增模块依赖边界检查，以及供 PR、main 和正式发布共同使用的后端门禁：完整测试覆盖 CGO+mmap 和无CGO+classic，竞态检查包含 BT、下载、媒体检查、编排和流媒体。测试数据库夹具改为纯 Go SQLite，生产数据库选择不变。设计文档列明已落实的边界、剩余接口债务和后续迁移的验收条件。
