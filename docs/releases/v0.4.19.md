# AniDog v0.4.19

下载当前状态以实际归档为依据：合集完成及启动恢复时，只有已完成合集中明确映射、文件仍存在的剧集，才能收口旧单集失败。旧的失败原因、字幕证据与保留成片继续保留，可在合集的分页尝试历史查看；文件缺失、映射不明和整季升级任务不会被误标为已解决。

保留成片复核与 BT 验收恢复使用设置页实际生效的媒体目录。历史 404、网络探测超时显示为执行故障；探测工具故障单独分类，旧 rejected 标记本身不能证明内容不符合或来源故障。已有明确错误码继续优先。

继承 v0.4.17 的跨来源内容指纹、字幕证据持久化、OCR 改进、重复传输预检和当前剧集/分页历史展示，保持 1080p 与简中要求。字幕未知保留待复核，不自动放宽要求或重复下载。

回归增加合集实时完成和启动收口、缺失文件与错误归属保护、升级任务保护、原始证据保留、合集尝试分页、运行时目录覆盖、BT 暂存与归档不同目录，以及旧失败分类。下载页顶部总数使用服务端总数，不再显示当前页条数。
