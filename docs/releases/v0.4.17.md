# AniDog v0.4.17

下载页按剧集展示当前结果，候选不符合、字幕待复核、跳过重复传输与执行故障分别统计；所有尝试保留在可分页查看的历史中，统计不再受最近 500 条限制。

- 以完整视频码流指纹和识别器版本保存来源无关的字幕事实。繁体、未知、工具故障以及简中通过均保留诊断；相同视频复用事实后按当前要求重新判定。工具故障不污染内容缓存。
- 预检可精确比较既有字幕画面，跳过已检查视频的重复传输；先检查新文件自己的字幕轨，避免误伤加了简中字幕的同视频版本。画面匹配不代替整集身份、完整性和字幕验收。
- 新增字幕区域定位、描边处理与独立 OCR 读数核对。识别冲突不提供简中证据，1080p 和简中门槛保持。
- 未知字幕保留为待复核，不盲目自动重复检查；异步复核直接读取现有成片，不能绕过身份复核入库。BT 单集也支持完成成片的验收恢复。

回归覆盖内容变化与重启复用、并发检查合并、故障不缓存、偏好变化、重复画面与不同画面、未知证据、取消、保留文件、候选结果投影、超过 500 次尝试的准确统计，以及每集历史的分页和真实渲染。
