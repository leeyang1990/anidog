# AniDog v0.4.18

保留成片复核与 BT 验收恢复统一使用设置页生效的媒体目录，修复通过运行时设置配置目录时，复核错误拒绝现有文件的问题。仍验证普通文件、真实路径和符号链接边界，不放宽文件访问范围。

历史失败通过同一兼容边界解释：404、网络探测超时显示为执行故障，探测工具故障独立分类；旧的 rejected 标记本身不能证明成片不符合要求。已有明确错误码继续优先，实际 720p、剧集身份错误继续归为候选不符合要求。

新增回归覆盖运行时目录与配置回退不同、BT 暂存路径与归档目录不同、越界路径拒绝、后台复核不归档，以及历史网络错误和真实候选拒绝的分类差异。继承 v0.4.17 的跨来源内容证据、OCR、去重和当前剧集/历史尝试机制，保持 1080p 和简中要求。
