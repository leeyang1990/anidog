# v0.4.32

修复共享字幕检查在并发取消和显式复核时的两个边界问题，保持 1080p、简中和禁止偏好回退。

- 检查执行归属与观测来源分开：有效内容事实可以复用，取消、工具失败或源文件错误只归属于实际执行该检查的请求。其余仍有效的请求继续使用自身上下文及保留文件执行检查，避免被另一个任务误标为失败。
- 显式复核加入并发工作后，会确认该结果是否满足本次重新测量的要求。旧缓存中的未知结论不能冒充新识别；已有明确语言事实和实际新测量仍可共享，避免重复 OCR。
- 协调器集中管理上述合并语义；下载服务继续负责完整文件身份、持久证据、来源和归档。保留既有检查并发限制与上下文预算，没有脱离任务生命周期的后台 OCR，也没有新增下载状态机。

确定性并发回归使用 Go synctest，覆盖主请求取消、等待者取消、执行错误、可重试工具失败、缓存未知、新测量未知与明确语言事实。服务流程回归验证：取消一个来源后，另一份真实保留文件正常验收归档，字节保持一致，不重新传输，并保留正确测量来源。识别回调仅在并发流程回归中受控；完整端到端仍使用正式 OCR 工具、独立 BT、PostgreSQL 和媒体文件验收。

全量 race 检查另外发现 BT 依赖的 v2 分片哈希更新与存储回写读数存在数据竞争。现在以不可变的原子快照发布完整哈希，存储适配器持有的旧哈希不再指向会被修改的数组。保留原锁顺序、Merkle 校验和协议断言；新增通过公开 Client API 反复更新合法 piece layers 的存储身份回归。三个依赖源文件的更新继续由原六文件精确摘要检查约束，没有扩大允许任意差异的范围。
