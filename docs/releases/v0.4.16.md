# AniDog v0.4.16

修复远程硬字幕抽帧消耗检查预算、合格剧集无法完成下载的问题。继承 v0.4.15 的统一失败语义、质量策略、身份匹配及完成后质量审计。

- 预检继续验证实际分辨率、参考片长和容量。硬字幕证据未知时进入独立暂存区，完整下载后在本地检查；只有符合用户画质与字幕要求的成片才能归档。流媒体目录中的“简中”标签不作为成片证据。
- 持久保存待验收成片的路径、归档目标及实际体积。检查工具或归档暂时失败时，任务进入明确的失败状态并保留文件；重启、显式重试及有次数限制的自动恢复继续验收同一文件，不重复取流、不创建新下载记录、不重复预留已下载体积。
- 恢复验收重新读取当前偏好并清除旧字幕证据；传统字幕、无法确认的字幕和低分辨率仍会拒收。自动流媒体字幕门槛不受可选成片检查开关影响。
- 本地验收按现有流媒体并发配置限制工作数，等待中的验收也能取消。明确取消不会由该成片恢复流程重新启动。
- 耗时检查不再持有全局归档锁。数据库事务继续重读候选状态后选出赢家，保护暂停、取消、同集竞速、已有文件及文件移动后提交失败的恢复边界。
- 下载页显示“正在检查成片，验证画质和字幕后入库”。数据库新增的暂存验收字段均提供兼容默认值。

回归覆盖本地字幕通过/拒收/工具故障、目录标签伪装、关闭可选检查后的严格验收、同文件手动/自动/重启恢复、取消与耗尽预算、并发认领、路径/符号链接保护、文件移动与提交间隙，以及跨剧集归档不会被 OCR 阻塞。
